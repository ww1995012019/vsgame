# 街头对决 · STREET DUEL

以雨夜九龙街机效果图为基础制作的可玩浏览器格斗游戏。v1.4 按用户选择优先修复人物动作与战斗判定：保留烈影、寒锋的原始图集，使用分区网格蒙皮与双腿 IK；头部独立采样，空中出招时腿部继续使用跳跃姿势。招式前摇、有效帧、后摇来自同一套 60 Hz 配置，命中通过独立攻击框与身体受击框求交。

上传的完整设计参考保存在 [设计文档](docs/street_duel_game_design.md)，本轮交付、验收方法与素材缺口见 [修复范围](docs/current-scope.md)。当前每人只有 8 张完整姿态图，缺少完整分层身体与空中踢腿、倒地、起身等专用资源；这是原图蒙皮与现有姿态结合的实现，尚未具备文档要求的全套动画资源。

## Site 部署

```bash
npm run build:site
```

部署目录是 `dist/client`，其中包含网页、样式、脚本和全部图片，可直接托管为静态网站。仓库根目录的 `.openai/hosting.json` 将 Site 静态目录指向该路径。无需服务器端密钥或数据库。

发布云环境与部署到网站是两项独立操作；需要 Site 已连接到当前环境，才能通过其部署通道取得网站地址。

## 启动

需要 **Node.js 22.7 或更高版本**。无 npm 依赖，无需安装，也不需要 API 密钥、数据库或外部服务。

```bash
cd /workspace/vsgame
npm run dev
```

服务默认监听 `0.0.0.0:3000`；可以用 `PORT=8080 npm run dev` 更换端口。用浏览器访问运行该服务的机器的对应端口即可游玩。所有美术资源均在仓库内，运行时不请求第三方服务。

也可以生成一个无需服务、无需联网的单文件版本：

```bash
npm run build
```

使用现代浏览器直接打开生成的 `dist/street-duel.html` 即可游玩。角色、街景、代码均内嵌在文件中；这个版本与开发版使用相同的游戏代码。

### 聊天文件预览

聊天内置文件预览可能禁止运行游戏脚本。页面现在会直接展示样式、街景和角色，并标注「界面预览」，不再依赖脚本初始化图片，也不会一直卡在加载遮罩。完整操作需将游戏文件下载后在 Chrome、Edge 等现代浏览器中打开。

构建同时生成带版本号的 `dist/street-duel-v1.4.0.html`，可用新文件替换之前下载或缓存的旧版。开发版的 CSS、脚本和图片均使用相对路径，可放在子目录中运行。

## 玩法

点击「开始对战」或按 Enter。对战电脑，99 秒一回合，先赢两回合获得比赛胜利；时间结束时比较生命值，平局不计胜场。

| 按键 | 操作 |
| --- | --- |
| A / D，或 ← / → | 左右移动 |
| W，或 ↑ | 跳跃，可跳过对手并切换朝向 |
| S，或 ↓ | 下蹲 |
| 相对朝向的后方向 | 对手攻击接近时站立防御；加 S/↓ 为蹲防 |
| J | 快速出拳 |
| K | 重踢，距离更远、击退更强 |
| L | 角色远程必杀，消耗 50 气 |
| O | 角色近身技能，消耗 35 气 |
| B | 显示 / 隐藏骨骼关节（设置中也可切换） |
| F3 | 显示 / 隐藏判定框、状态、招式帧和命中结果 |
| Esc | 暂停 / 继续 |

画面底部会显示当前角色的技能名和耗气，也可以直接点击技能按钮；手机保留独立的「远程」「近身」触屏按钮。命中和格挡积攒能量；对手仍处于受击控制期间继续命中才累计连击，恢复后重新计数。轻拳命中后可在取消窗口接重踢或技能，重踢可接技能，输入缓冲为 8 帧。F3 显示实际判定：黄框为碰撞框，蓝框为受击框，红框为有效攻击框。手机提供屏幕方向键和出招按钮，横屏操作空间更大。

- **角色**：烈影保留黑发、黄衣、红手套、深色长裤；寒锋保留白发、藏青背心、白裤和红腰带。战斗、角色选择和头像均沿用仓库原图，不重绘角色。
- **烈影 · 赤焰掌（L）**：金橙色火焰弹，适合远程压制。
- **烈影 · 流火冲拳（O）**：金红残影突进后挥拳，在身体接触前停止，不能穿过对手。
- **寒锋 · 冰棱破（L）**：青蓝色冰晶弹，比火焰弹更快，命中硬直更久。
- **寒锋 · 霜环升龙（O）**：青蓝冰环上勾拳，命中会将对手挑空；格挡能防止挑空。
- **训练场**：静止陪练、无限时间、快速恢复能量；陪练被击倒后恢复，可查看命中数和累计伤害。
- **设置**：三档电脑难度、音量、屏幕震动和雨景开关。设置保存在当前浏览器中。
- **排行榜**：记录当前浏览器最近 30 场完整比赛的胜负、比分和最高连击；不连接在线排名服务。
- **重新开始**：重置当前比赛或训练。

切出页面时正在进行的比赛会自动暂停。音效由 Web Audio 实时合成，在首次点击或按键后启用。关闭浏览器会结束未完成的比赛。

## 验证

```bash
npm run check
npm test
```

纯逻辑测试涵盖原图 SHA-256、16 个原画姿态绑定、蒙皮权重与骨长、行走/跳跃过渡，以及实际矩形求交、有效帧、同帧相杀、墙角分离、落地动作限制、换边防御、高低段格挡、8 帧输入缓冲、命中取消、真连击、弹体扫掠、挑空与落地恢复、四种技能、计时和回合规则。跳跃能否避开攻击取决于实际身体框位置，不使用根节点高度提供额外免伤。

可选的实际浏览器检查需要 Python Playwright 与 Chromium。先启动服务，再在另一个终端执行：

```bash
python3 tests/browser_smoke.py
python3 tests/art_browser_smoke.py
python3 tests/locomotion_browser.py
python3 tests/combat_browser.py
```

可以用 `CHROMIUM_PATH` 指定浏览器可执行文件，用 `GAME_URL` 指定测试服务地址。测试会实际操作键盘和触屏按钮，覆盖出招命中、设置、角色切换、回合结算、战绩持久化和手机布局，并将截图保存在被 Git 忽略的 `test-results/`。回合结算测试会将对手设为残血，再通过真实键盘攻击完成击倒。

预览兼容性回归检查（同样需要 Playwright 和 Chromium，无需提前启动服务）：

```bash
npm run build
npm run test:preview
```

它会实际验证子目录加载、禁用脚本、受限 iframe 预览和断网运行的单文件游戏。

## 文件

```text
index.html             界面、状态栏和对话框
src/style.css          视觉布局与响应式界面
src/engine.js          独立的对战模拟、物理、AI 与胜负规则
src/combat.js          状态权限、60 Hz 帧数据、Hitbox/Hurtbox/Pushbox 与格挡规则
src/motion.js          行走步幅、起跳预备、重力和落地时序
src/rig.js             原图关节数据、行走/跳跃动作、双腿 IK、分区网格权重与骨骼变换
src/skin.js            头部刚性蒙皮、独立双腿蒙皮、共享 WebGL 图层及 Canvas 降级
src/renderer.js        骨骼角色渲染、雨景、火焰/冰晶/突进/升龙特效与合成音效
src/app.js             输入、界面同步、设置与本地战绩
public/assets/         原场景、角色动作图集与视觉参考
public/motion-review.html  0.25 倍慢放、暂停、逐帧、骨骼动作预览
server.mjs             无依赖静态文件服务
tests/                 游戏逻辑与浏览器验证
```

当前是单人对电脑的本地街机版本。移动和跳跃使用独立的头部、躯干和双腿蒙皮，大幅度出招沿用原图姿态；每个顶点最多受四根骨骼影响。B 键显示求解后、实际驱动网格的关节。可打开 `public/motion-review.html` 慢放、暂停、逐帧查看两个角色的行走、跳跃及近身技能。仓库没有独立身体分层，当前蒙皮沿用原画可见纹理，不生成新视角或被遮挡区域。没有在线联机或服务端账户。
