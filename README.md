# 街头对决 · STREET DUEL

以雨夜九龙街机效果图为基础制作的可玩浏览器格斗游戏。原创场景和角色动作图集与实际游戏逻辑分开渲染；不是点击一张静态截图。

## Site 部署

```bash
npm run build:site
```

部署目录是 `dist/site`，其中包含网页、样式、脚本和全部图片，可直接托管为静态网站。仓库根目录的 `.openai/hosting.json` 将 Site 静态目录指向该路径。无需服务器端密钥或数据库。

发布云环境与部署到网站是两项独立操作；需要 Site 已连接到当前环境，才能通过其部署通道取得网站地址。

## 启动

需要 **Node.js 22.7 或更高版本**。无 npm 依赖，无需安装，也不需要 API 密钥、数据库或外部服务。

```bash
cd /workspace/vsgame
npm run dev
```

服务默认监听 `0.0.0.0:3000`；可以用 `PORT=8080 npm run dev` 更换端口。用浏览器访问运行该服务的机器的对应端口即可游玩。所有美术资源均在仓库内，运行时不请求第三方服务。

也可以生成一个无需服务、无需联网的单文件版本：

```bash
npm run build
```

使用现代浏览器直接打开生成的 `dist/street-duel.html` 即可游玩。角色、街景、代码均内嵌在文件中；这个版本与开发版使用相同的游戏代码。

### 聊天文件预览

聊天内置文件预览可能禁止运行游戏脚本。页面现在会直接展示样式、街景和角色，并标注「界面预览」，不再依赖脚本初始化图片，也不会一直卡在加载遮罩。完整操作需将游戏文件下载后在 Chrome、Edge 等现代浏览器中打开。

构建同时生成带版本号的 `dist/street-duel-v1.0.1.html`，可用新文件替换之前下载或缓存的旧版。开发版的 CSS、脚本和图片均使用相对路径，可放在子目录中运行。

## 玩法

点击「开始对战」或按 Enter。对战电脑，90 秒一回合，先赢两回合获得比赛胜利；时间结束时比较生命值，平局不计胜场。

| 按键 | 操作 |
| --- | --- |
| A / D，或 ← / → | 左右移动 |
| W，或 ↑ | 跳跃，可跳过对手并切换朝向 |
| S，或 ↓ | 站立格挡，降低伤害 |
| J | 快速出拳 |
| K | 重踢，距离更远、击退更强 |
| L | 能量波必杀，消耗 50 气 |
| Esc | 暂停 / 继续 |

命中和格挡积攒能量；短时间内连续命中会显示连击数。移动到攻击距离后出招，攻击范围之外不会命中。手机提供屏幕方向键和出招按钮，横屏操作空间更大。

- **角色**：烈影速度更快，寒锋攻击更重。选好后开始一场新对战。
- **训练场**：静止陪练、无限时间、快速恢复能量；陪练被击倒后恢复，可查看命中数和累计伤害。
- **设置**：三档电脑难度、音量、屏幕震动和雨景开关。设置保存在当前浏览器中。
- **排行榜**：记录当前浏览器最近 30 场完整比赛的胜负、比分和最高连击；不连接在线排名服务。
- **重新开始**：重置当前比赛或训练。

切出页面时正在进行的比赛会自动暂停。音效由 Web Audio 实时合成，在首次点击或按键后启用。关闭浏览器会结束未完成的比赛。

## 验证

```bash
npm run check
npm test
```

17 项纯逻辑测试涵盖移动、跳跃、距离与有效帧判定、格挡、能量波、连击、暂停、计时、平局、三局两胜、电脑攻击、角色切换、音效事件、快速按键和连招输入缓冲。

可选的实际浏览器检查需要 Python Playwright 与 Chromium。先启动服务，再在另一个终端执行：

```bash
python3 tests/browser_smoke.py
```

可以用 `CHROMIUM_PATH` 指定浏览器可执行文件，用 `GAME_URL` 指定测试服务地址。测试会实际操作键盘和触屏按钮，覆盖出招命中、设置、角色切换、回合结算、战绩持久化和手机布局，并将截图保存在被 Git 忽略的 `test-results/`。回合结算测试会将对手设为残血，再通过真实键盘攻击完成击倒。

预览兼容性回归检查（同样需要 Playwright 和 Chromium，无需提前启动服务）：

```bash
npm run build
npm run test:preview
```

它会实际验证子目录加载、禁用脚本、受限 iframe 预览和断网运行的单文件游戏。

## 文件

```text
index.html             界面、状态栏和对话框
src/style.css          视觉布局与响应式界面
src/engine.js          独立的对战模拟、物理、AI 与胜负规则
src/renderer.js        Canvas 动作、雨景、打击特效与合成音效
src/app.js             输入、界面同步、设置与本地战绩
public/assets/         原创生成场景、角色动作图集与视觉参考
server.mjs             无依赖静态文件服务
tests/                 游戏逻辑与浏览器验证
```

当前是单人对电脑的本地街机版本，使用八个独立动作姿态与程序动画；与概念图保持视觉风格和布局一致，动态战斗画面会随实际操作变化。没有在线联机或服务端账户。
